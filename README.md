# 🩸 Emergency Blood Request and Donor Management System

A Flask-based web application that helps hospitals manage emergency blood requests by connecting patients with registered blood donors. The system supports donor registration, hospital management, patient requests, and automatic email notifications to eligible donors.

---

## 📌 Project Overview

The Emergency Blood Request and Donor Management System simplifies the process of finding blood donors during emergencies. Hospitals can register, add patient blood requests, and automatically notify matching donors through email, reducing the time required to arrange blood donations.

---

## ✨ Features

- 👤 Donor Registration and Login
- 🏥 Hospital Registration and Login
- 🩸 Blood Donor Management
- ❤️ Patient Blood Request Management
- 📋 View and Manage Donor Records
- 📧 Automatic Email Notification to Eligible Donors
- 🔒 Secure Authentication System
- 💾 SQLite Database Integration

## 🚀 Installation & Usage

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/harshitha-c-2004/Emergency-Blood-Request-and-Donor-Management-System.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd Emergency-Blood-Request-and-Donor-Management-System
```

### 3️⃣ Install Required Packages

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
python app.py
```
